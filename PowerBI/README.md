# Healthcare Insurance Claims Analytics – Power BI

## Project Overview

This project is an interactive Power BI dashboard developed to analyze healthcare insurance claims data.

The dashboard provides insights into claim amounts, patient demographics, medical conditions, hospital information, insurance providers, claim status, and overall healthcare claim patterns.

## Objectives

- Analyze healthcare insurance claim trends
- Understand claim amounts and claim distribution
- Analyze patient demographics and medical conditions
- Compare hospitals and insurance providers
- Identify patterns in claim status
- Present key insights through interactive Power BI visualizations

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel / CSV Dataset

## Key Power BI Features

- KPI Cards
- Interactive Charts
- Slicers
- Filters
- DAX Measures
- Data Cleaning using Power Query
- Data Modeling
- Interactive Dashboard Navigation

## Dashboard

The Power BI dashboard contains multiple visualizations designed to provide an overall view of healthcare insurance claims and allow users to explore the data interactively.

## Project File

The `.pbix` file included in this folder contains the complete Power BI dashboard and its underlying data model.
